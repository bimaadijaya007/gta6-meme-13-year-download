An original meme (`meme.png`, 1600×1600) for make.fun's "Post a GTA 6 meme on Reddit" bounty ($500): the make.fun ghost with its sparkle eyes and magenta star coin, on a pink convertible in neon Vice City, holding a phone whose GTA VI download bar is stuck at 99%.

The meme is ready to post — see `POSTING.md` for the suggested title, body and subreddit steps. `POST.json` still holds the kit's placeholder address until the meme is posted on Reddit; once it is live, replace the placeholder with the post's address and resubmit before the deadline (2026-11-23 21:00 WIB).

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` and `meme.png` to the output directory and writes `dossier.json` with the meme's title, captions, suggested Reddit title/body and the post's status.
